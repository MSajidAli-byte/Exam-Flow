# Research Experimental Data

This folder contains the raw reports and analysis JSONs for the curated trials used in the Phase 2 research paper.

## Trials Overview

1. **Trial 1 (Honest Student)**: Baseline proof that normal behavior is not penalized.
2. **Trial 2 (Sudden Logic)**: Proof of copy-paste detection.
3. **Trial 3 (Paradigm Mismatch)**: Proof of submission tampering detection (Python vs Java).
4. **Trial 4 (External Reference)**: Proof of correlate visual behavior with on-screen events.

## Why this matters

These trials represent "Ground Truth" for scientific validation.
